#### Caso de Estudio
- Sistema de gestión de almacén e inventario

#### Descripción Breve del Sistema
Desarrollo e implementación de un sistema de gestión de almacenes e inventarios para la empresa LogiStock, diseñado para optimizar y automatizar las operaciones logísticas mediante el control de inventario en tiempo real, la trazabilidad de mercancías y la integración con dispositivos de entrada de datos, como Lector de Códigos de Barras/RFID.

#### Relación de Diagramas
Cada diagrama aportó una perspectiva distinta del sistema. El diagrama de casos de uso definió el alcance funcional, identificando los roles internos y los actores externos que interactúan con el sistema. Los diagramas de secuencia y de comunicación, por su parte, representaron el proceso de registro de ingreso de mercancía desde dos enfoques: uno basado en el orden cronológico de los mensajes y otro en la relación entre los objetos participantes, al coincidir en el flujo del proceso se confirma que el comportamiento modelado es correcto y fácil de seguir
